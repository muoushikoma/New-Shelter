# 《避难所》 游戏策划案 v0.1

> 类型：本格生存 × 涌现式社会模拟 × 成人向叙事
> 画面：精致像素风（2D 侧剖面），原生分辨率 480×270，整数倍放大
> 平台：PC（Windows / macOS / Linux），首发 Steam（成人内容以独立补丁/开关形式提供）
> 叙事骨架：**目标节点网络**（无主线），详见 `docs/GOAL_NETWORK.md`
> 分级：18+。所有可登场角色由生成器强制为成年人（20–65 岁），内容层无法覆盖此约束。

---

## 0. 一句话

**战争爆发的那一夜，几个互不相识的人逃进独裁国家边境上一座废弃的民防避难所。门关上以后，这里就成了一个新的国家。**

## 1. 我对这个项目的理解

你想做的不是「生存游戏 + 色情要素」，而是一个**社会实验箱**：

1. **本格生存**是压力源。热量、水、体温、空气、伤病、睡眠——它们必须真实、可计算、不可作弊。只有资源真的不够，人才会露出本来面目。
2. **小社会**是实验对象。没有剧本规定谁当头、谁背叛。秩序（或无序）是从每个 NPC 自己的算计里**长出来**的。
3. **权力与性**是这个社会最赤裸的两条神经。在稀缺之下，性可以是爱、慰藉、交易、讨好、武器，也可以是支配与被支配的证据。游戏不评判，但**系统记得**——每一次都有后果：信任、怨恨、流言、创伤、依附、报复。
4. **隐喻**是目的。避难所外面是一个独裁国家和一场战争；避难所里面，玩家会亲眼看到（或亲手造出）一个微缩的独裁、一个公社、一个丛林，或者什么都不是。门外的广播在说什么，门里就有人开始学着说。
5. **玩家不是上帝**。你只控制一个人，一具会饿、会冷、会害怕、会被睡、会被打的身体。你可以争当领袖，也可以低头做顺民、做情人、做告密者、做逃兵。别人和你一样在算计。
6. **没有主线，只有目标网络**。唯一默认目标是「活下去」。离开、掌权、爱情、财富、依附、重建……都是网络中的节点与路线。每个节点有多种解法，路线之间共享节点、相互交叉，NPC 也在这张网上追求他们自己的目标。结局由组合生成，不分好坏。（详见 `docs/GOAL_NETWORK.md`）

**设计原则：凡是现实中在那种环境里可能发生的事，系统都应该允许它发生；凡是发生了的事，系统都应该让它产生后果。**

## 2. 世界观

### 2.1 国家：统一阵线国

- 一个存在了四十年的一党制国家，由「领袖」和「阵线」统治。宣传、配给、告密、劳动营构成了国民的日常。
- 国民习惯了：说一套做一套、互相监视、对权力的本能服从或本能怀疑。**这些习惯会被带进避难所。** 每个角色都有「对政权态度」这一维度，决定他们在避难所里更倾向于重建等级，还是反抗等级。

### 2.2 地点：灰河镇 · 第 7 号民防避难所

- 北部边境小镇，冬季，最低温 -25°C。镇外是界河和边境线。
- 避难所建于半世纪前「备战备荒」时期，早已废弃：发电机老化、通风系统半堵、储藏室被搬空了大半，墙上还残留着领袖画像和标语。
- 地表：被炮火摧毁的小镇、医院、粮站、阵线党部、火车站、教堂、边境哨所、雷区、森林。

### 2.3 战争时间线 = 外部时钟（动态，每局随机偏移）

> 时间线不是剧情，而是**开关窗口的时钟**：每个阶段都会打开一些节点/解法、关闭另一些（例如宪兵撤离后，依赖宪兵的通行解法全部失效；占领后，旧政权证件变成罪证）。

| 阶段 | 大约天数 | 外部状况 | 对避难所的影响 |
|---|---|---|---|
| 一、崩溃 | 1–7 | 前线溃败，政府军后撤，宪兵队搜捕逃兵、强征壮丁 | 广播号召「坚守、举报叛徒」；有人敲门 |
| 二、炮火 | 8–20 | 前线经过灰河镇，炮击、断电、空袭 | 地表探索极度危险；伤员、震塌 |
| 三、占领 | 21–40 | 敌军/起义军占领镇子，搜查、征粮、清算「阵线分子」 | 身份成为致命问题（老干部、逃兵、通敌者） |
| 四、终局 | 40+ | 停火 / 政权反扑 / 彻底崩溃，三选一（由世界状态和随机决定） | 不同终局清算避难所里发生过的一切 |

> 外部不是背景板：广播内容、来客、地表资源、搜查队，都会随阶段变化，并且**会被避难所里的人利用**（比如以「举报」相威胁）。

## 3. 核心玩法循环

```
 ┌──────────────── 一天（24 小时，实时 + 可暂停，1 游戏分钟 ≈ 0.5 秒） ────────────────┐
 │                                                                                      │
 │  身体需求（饿/渴/冷/困/病/欲）──► 你去做事：做饭、修机器、睡觉、聊天、偷东西、找人…  │
 │         ▲                                    │                                       │
 │         │                                    ▼                                       │
 │  资源消耗与产出 ◄──── 其他 NPC 也在自主做事、互相交往、结盟、交易、算计               │
 │         │                                    │                                       │
 │         ▼                                    ▼                                       │
 │  稀缺 ──► 冲突事件（分配、偷窃、争吵、性、暴力、外来者）──► 关系/记忆/流言/规则变化 │
 │                                                                                      │
 └──────── 夜里：地表探索（可选，派人或亲自去）── 新资源 / 新危险 / 新的人 ───────────┘
                              │
  目标层：日常行动 ──► 推进 / 竞争 / 阻断网络中的节点（玩家与 NPC 共用一张网）──► 世界状态变化
                              │
                 长期：外部时钟推进 → 窗口开合 → 终止节点 或 终局清算
```

- **一局时长**：40–60 个游戏日，约 6–10 小时；若中途到达终止节点（如越境、死亡）会提前结束。随机开局 + 永久死亡 + 组合式结局 → 高重玩性。
- **主角**：开局从 6 种出身中随机（或选择）一个：逃兵、前干部、医生/护士、工人、知识分子、外国人/少数民族。出身决定初始技能、秘密，以及别人对你的初始态度。
- **其他人**：从角色池 + 程序化生成中抽取 4–7 人。每局人员组合不同，社会也不同。

## 4. 本格生存系统

所有数值都以**真实单位**建模，界面上可以简化显示，但底层不糊弄。

### 4.1 身体

| 维度 | 底层模型 | 后果 |
|---|---|---|
| 热量 | 每人每日消耗 1800–3200 kcal（性别、体型、劳动强度、体温） | 饥饿 → 虚弱 → 免疫下降 → 饿死（约 3–6 周） |
| 水 | 每日 2–3 L；储水罐、雪水（需燃料煮沸）、地下渗水（需过滤） | 脱水 3 天致死；生水 → 腹泻/痢疾 |
| 体温 | 室温由发电机/暖炉/人数/通风决定；衣物、毛毯、**同床取暖** | 失温、冻伤（截肢）；「抱团取暖」本身就是亲密事件的入口 |
| 空气 | CO₂ 浓度随人数与通风；手摇通风机需要人力 | 头痛、嗜睡、判断下降；密闭过久致死 |
| 睡眠 | 床位少于人数；轮班；噪音和恐惧影响质量 | 睡眠剥夺 → 易怒、幻觉、事故 |
| 伤病 | 部位伤（流血/骨折/感染）、疾病（流感、痢疾、肺炎、坏疽）、慢性病（糖尿病、心脏病）、成瘾 | 药品是最硬的硬通货；没有医生时，谁来截肢？ |
| 卫生 | 粪桶、排污、洗澡水 | 疾病爆发、羞耻、隐私冲突 |
| 生育（可开关） | 避孕套/药物稀缺；怀孕周期真实；分娩风险 | 一个孩子会彻底改变一个小社会 |

### 4.2 心理

- **压力**：饥饿、黑暗、炮击、死亡、背叛、性创伤都会累积压力。
- **心境**：在压力、希望、亲密、意义感之间波动。
- **崩溃与后遗**：恐慌、歇斯底里、抑郁、麻木、PTSD 闪回、自伤、自杀、施暴、宗教狂热。
- **慰藉源**：烟、酒、祈祷、音乐、性、陪伴、权力感、复仇。**每个人的慰藉源不同**，这决定了他们在压力下会去找什么、找谁。

### 4.3 设施（侧剖面房间）

入口气闸 · 仓库 · 厨房/公共区 · 宿舍 · 发电机房 · 医务室 · 水房/厕所 · 通风井 · 档案室（锁着，藏着秘密）· 可清理出的隐蔽小间。

- 每个设施有耐久、需要维护、可以改造（加锁、加帘子、加隔断、加岗哨）。
- **改造是政治行为**：给仓库加锁 = 谁拿钥匙；给宿舍加帘子 = 隐私权；把小间改成禁闭室 = 刑罚的诞生。

### 4.4 资源与经济

- **公共库存 vs 私人物品**：每件物品都有「归属」。私藏、偷窃、赠与、交易都会被追踪（但不一定被**别人**知道）。
- **硬通货自然出现**：香烟、酒、药、子弹、巧克力、避孕套。没有预设汇率，NPC 按自己的需求估价。
- **人情与债务**：「你欠我一次」会被记住，并在关键时刻兑现或翻旧账。
- **地表探索**：夜间出行（白天会被狙击/巡逻发现）。节点式地图 + 小场景潜行搜刮。携带量、体温、噪音、巡逻视野、地雷、尸体、其他幸存者、被抓走。

## 5. NPC 自主行为（AI 设计）

> 目标：每个 NPC 都是一个**自私但合理**的人。玩家应该能事后回溯并理解「他为什么那么做」。

### 5.1 人物模型

```
Character
├─ 身份：姓名、年龄(20–65)、性别、性取向、出身、职业、外貌、秘密(1–3个)
├─ 身体：需求条 + 伤病 + 技能(医疗/机械/烹饪/战斗/潜行/说服/…)
├─ 人格（0–100）
│   ├─ 大五：开放、尽责、外向、宜人、神经质
│   ├─ 权力欲        想控制别人/资源的程度
│   ├─ 道德底线      做「坏事」所需的压力阈值（不是固定善恶，是会被饥饿磨低的）
│   ├─ 亲密/欲望需求  对情感与性接触的需求强度与类型
│   ├─ 恐惧阈值      多大的威胁让他服从
│   ├─ 依附性        倾向依附强者还是独立
│   └─ 政权态度      忠诚 / 犬儒 / 反抗  —— 影响他想重建什么样的秩序
├─ 记忆：带情绪权重的事件列表（会衰减、会被反复想起而加深）
├─ 信念：对「世界与他人」的认知 —— 可能是错的（流言、误会、伪装）
└─ 对每个人的看法（多维）
    信任 · 好感 · 尊重 · 畏惧 · 欲望 · 恩情/债务 · 嫉妒 · 怨恨
```

### 5.2 决策架构：效用 AI + 轻量计划器

1. **需求 → 动机**：每个 tick 计算各动机强度（活下去、舒适、安全、亲密、地位、复仇、意义……），由需求、人格、记忆、当前局势加权。
2. **动机 → 候选行动**：行动库约 120 种（见 5.3），每个行动声明「满足哪些动机、风险是什么、需要什么前提」。
3. **主观评估**：NPC 用**自己的信念**而不是真相来估算风险（他以为没人看见，就会去偷）。
4. **多步计划（GOAP-lite）**：复杂意图会展开成计划——
   例：「我要当头」→ 拉拢 2 人 → 掌握仓库钥匙 → 在会议上提议改分配制度 → 若失败，夜里夺枪。
5. **执行可被打断**：被撞见、被拒绝、被威胁，都会重新规划。
6. **可读性**：玩家可以通过「观察」看到 NPC 的情绪与粗略意图（取决于你和他的关系与你的洞察力），通过「深谈」挖出更多；**永远看不到全部**。

### 5.3 行动库（节选）

| 类别 | 行动 |
|---|---|
| 生存 | 吃、喝、睡、做饭、修理、通风、照顾病人、清理排泄物、出外搜刮、站岗 |
| 社交 | 闲聊、倾诉、安慰、开玩笑、讲故事、一起祈祷、分享食物、吵架、冷战、道歉 |
| 信息 | 打听、散布流言、揭发、撒谎、保守秘密、偷看、偷听、翻别人东西 |
| 经济 | 交易、借贷、赠与、索债、私藏、偷窃、贿赂 |
| 政治 | 提议规则、召集会议、投票、拉票、结盟、背叛盟友、夺权、罢工、拒绝命令、自封 |
| 强制 | 威胁、勒索、殴打、禁闭、没收、驱逐、处决、夺枪 |
| 亲密 | 调情、示好、拥抱、同床取暖、求爱、发生关系、拒绝、分手、吃醋、交易性关系、利用性施压 |
| 退出 | 出走、自杀、向外部（宪兵/占领军）告密、带人私奔 |

### 5.4 社会信息传播

- **目击**：行为发生时，在视野/听力范围内的人会形成记忆。黑暗、帘子、噪音降低被目击概率。
- **流言**：记忆会被讲出去，每转述一次可能失真（夸大、张冠李戴）。人们根据对讲述者的信任决定信多少。
- **公开知识 vs 私密知识**：「大家都知道但没人说」是一个合法状态；一旦有人在会议上说出来，就变成必须回应的公共事件。

### 5.5 派系涌现

- 每天根据相互信任 + 利益一致度做聚类，自然形成派系（无需预设）。
- 派系有隐含领袖和隐含议程（如「先保证壮劳力吃饱」「女人和病人优先」「把老干部赶出去」）。
- 派系之间的张力超过阈值 → 公开冲突事件。

## 6. 权力系统

### 6.1 权力的来源（可叠加、可转换）

| 来源 | 获取方式 | 脆弱点 |
|---|---|---|
| **资源控制** | 拿着仓库钥匙、药、枪 | 被偷、被夺、被揭发私藏 |
| **暴力** | 体格、武器、打手 | 睡觉的时候 / 寡不敌众 |
| **合法性** | 投票、共识、能干、公正 | 一次被看见的不公 |
| **信息** | 掌握别人的秘密 | 对方先下手 |
| **外部背书** | 宣称与政权/占领军有联系；掌握电台 | 外部局势变化 |
| **亲密关系** | 情人、依附者、被保护者 | 嫉妒、分手、背叛 |

### 6.2 制度（「法令」）

只要有人提出、有人执行，制度就成立。制度不是 UI 开关，而是**持续的社会博弈**：每个 NPC 每天根据「畏惧 × 认可 × 自身利益」决定遵守、阳奉阴违还是公然违抗。

- **分配制度**：平均分配 / 按劳分配 / 按贡献积分 / 领袖分配 / 抽签 / 先来先得（无制度）
- **劳动制度**：自愿 / 排班 / 强制 / 以劳换食
- **武器制度**：公共保管 / 领袖持有 / 各自持有
- **门的制度**：外人一律不放 / 投票 / 有用的人才放
- **关系与身体的制度**：自由 / 禁止（以「秩序」为名）/ 领袖特权 / 以性换配给被默许 —— 每种都会把社会推向完全不同的方向
- **刑罚**：训诫 / 扣配给 / 禁闭 / 体罚 / 驱逐（等于死刑）/ 处决
- **决策方式**：全体会议 / 多数票 / 长老会 / 一人说了算

### 6.3 典型的政体演化（不预设，但系统支持）

- **公社**：平均分配 + 全体会议，在资源宽裕时稳定，在饥荒时极易被「搭便车」拖垮。
- **能人寡头**：最有用的两三个人默契地多吃多占，其余人沉默。
- **独裁**：一人控制钥匙和枪，以配给奖惩、以告密维持，宣传话术直接照搬广播。**玩家会发现自己可以非常自然地变成领袖的样子。**
- **丛林**：无制度，强者通吃，夜里互相防备。
- **神权**：某人在恐惧中成了「先知」。

### 6.4 玩家的位置

玩家不默认是领导者。掌权只是目标网络中的一条路线，与离开、财富、共同生活、依附、反抗、重建等并列，且共享大量节点（见 `docs/GOAL_NETWORK.md` §7）。

玩家路线**不是选出来的**，而是被你的行为和别人对你的看法定义的。游戏结束时会告诉你「在别人眼里，你是谁」。

## 7. 亲密、欲望与性（系统层；具体内容由内容层填写）

> 本节只描述**系统**。所有具体的文字与图像内容走「成人内容接口」，见 `docs/ADULT_CONTENT_INTERFACE.md`。未填写时，游戏以淡出/省略文本代替，系统后果照常生效。

### 7.1 欲望模型

- **吸引力矩阵**：基于性取向、外貌偏好、人格契合、当前状态（干净程度、健康、权力地位——**权力本身会改变吸引力**）。
- **需求**：亲密需求按人格不同增长速度不同；压力会放大或压抑它。
- **动机标签**：每一次亲密行为都会被系统打上动机标签（可多个）——
  `爱慕` `慰藉` `取暖` `交易` `讨好` `依附` `支配` `报复` `胁迫` `好奇` `逃避`。
- **意愿度（consent）**：由欲望、好感、信任、畏惧、绝望程度、权力差共同计算出来，分为：
  `主动` `情愿` `勉强` `屈从` `拒绝`。
  这个值是公开传给内容层的，也是系统后果的核心输入。

### 7.2 关系状态

`陌生 → 熟识 → 暧昧 → 恋人 / 情人 / 交易关系 / 庇护关系 / 支配关系`
关系可以并存（一个人可以同时是 A 的恋人和 B 的交易对象），也会互相发现。

### 7.3 权力与性的交织（核心表达）

| 情境 | 系统表现 |
|---|---|
| 以性换配给 / 药 / 保护 | 交易双方的关系、双方在他人眼中的形象、旁观者的嫉妒与道德判断都会变化 |
| 领袖的「特权」 | 合法性受损（在有些人眼中）或被默许（在有些人眼中）；依附者增多，暗中的怨恨也增多 |
| 被支配者的策略 | 屈从、讨好、利用、反抗、伺机报复、建立秘密盟友——**被支配的一方同样是有算计的行动者** |
| 用性去获得权力 | 成为领袖的枕边人从而间接掌权；挑拨两个强者 |
| 胁迫 | 系统允许其作为社会现实**存在**，但绝不奖励：施加者获得的短期利益伴随长期的创伤记忆、怨恨、流言、派系敌意、报复概率；受害者获得创伤状态与新的行动动机（复仇、出走、寻求庇护、崩溃）。在所有 UI 中都不会将其包装为「玩法奖励」。 |
| 嫉妒与独占 | 吃醋、争吵、斗殴、告发、「她是我的」式的占有宣言 —— 也可能演变为制度 |
| 隐私 | 帘子、小间、夜班、黑暗；被撞见 → 流言 → 公共事件 |

### 7.4 后果追踪

每次亲密事件结束后，系统必然执行（与内容层无关）：
1. 双方记忆写入（带动机标签与意愿度）
2. 关系多维值更新
3. 目击判定 → 流言种子
4. 生理：取暖/慰藉/压力变化；怀孕概率（若开启）；疾病传播（若开启）
5. 社会：嫉妒检查、派系态度、合法性变动

## 8. 事件系统

两类事件共存。在目标网络中，事件的作用是**开门、关门、提供线索**，而不是推进主线：

1. **涌现事件**：完全由模拟产生（「老周在仓库偷吃时被阿娜看见了」）。系统用模板句把它们呈现给玩家。
2. **叙事事件**：手写的情境模板，但**触发条件和参演角色由模拟决定**（「第一次分配会议」「有人敲门」「电台里念到了你的名字」「发电机坏了，只够给一个房间供暖」）。手写事件计划 120+ 个，每个有多分支，且 NPC 会**主动在事件中表态**，而不是等玩家选完。

事件呈现：像素小剧场 + 对话框 + 选项。选项会显示可能的反应预估（「老周会记住这件事」「需要：说服 40」），信息量受你的洞察力影响。

### 8.1 事件样例（摘要）

- **第一夜**：门外有人拍门，是一个带着孩子的母亲 —— 还是一个穿军装的人？放不放？谁去开门？
- **钥匙**：仓库只有一把钥匙。谁拿？
- **偷吃**：库存少了两罐肉。所有人都在看你/看他。
- **广播**：电台播报「通敌分子名单」，里面有一个名字和避难所里某人的旧名字一样。
- **取暖**：发电机只够一个房间。今晚大家挤在一起睡。
- **药**：只剩一支抗生素，两个人在发烧。
- **宪兵**：搜捕逃兵的队伍在门外。交出一个人，其他人就安全了——他们是这么说的。
- **审判**：有人提议「开会审一审」。审判本身就是权力的诞生仪式。
- **孩子**（若开启生育）：谁的？
- **最后一罐**：……

## 9. 终局与结局

结局由 6 个维度组合生成（你在哪、你是谁、你和谁在一起、避难所的命运、外部局势、你主要靠什么手段走到这里），详见 `docs/GOAL_NETWORK.md` §9。命中特定组合时触发 30+ 个有名字的标志性结局，并为每个角色生成独立后日谈。

例：
- **政权回归**：「坚守者」被表彰，告密记录被调阅。你曾在避难所里做过的事，被一份份口供写进档案。
- **占领军清算**：老干部被交出去了。是谁交的？
- **公社的冬天**：所有人都活了下来，但每个人都瘦得认不出彼此。
- **小领袖**：你走出避难所时，身后的人排成一列，低着头。广播里的声音和你的声音越来越像。
- **独自一人**：最后一个活着的人。

结局界面会展示：**谁活着、谁死了、怎么死的、谁和谁睡过（按动机标签）、谁恨谁、你在每个人眼中是谁**。

## 10. 美术方向

### 10.1 风格

- **精致像素**：原生 480×270，4× 放大到 1080p；人物 12×20 左右（场景内）/ 32×48 半身像（对话与档案）。
- **光影是第一主角**：避难所里大部分地方是黑的。每盏灯、发电机的红光、手电筒、烟头，都是可计算的光源，配合有序抖动（Bayer dither）形成柔和但颗粒的明暗过渡。灯光闪烁直接反映电力状况。
- **侧剖面**：像蚁巢，一眼看到所有房间里正在发生的事 —— 这是「社会模拟」可读性的关键；但房间里没灯时你**看不见**里面在干什么。
- **调色板**：冷（钢蓝、混凝土灰、雪）与暖（钨丝灯橙、火光、皮肤）对撞；政权元素用褪色的红；整体低饱和、高对比。
- **地表**：雪、灰烬、远处燃烧的城市映红天际、探照灯扫过。

### 10.2 UI

- 旧式民防设备 + 档案卷宗的质感：铁皮、铆钉、打字机字、手写批注、红色印章。
- 信息分层：常驻（时间/温度/库存/人员）→ 悬停（状态与情绪）→ 打开（档案/关系网/记忆）。
- 关系网可视化：线的颜色代表主导情感（信任蓝、好感绿、欲望品红、畏惧紫、怨恨红），粗细代表强度，虚线代表「你不确定」。

### 10.3 音频

- 环境音层：通风机、滴水、发电机、远处炮声、广播杂音、心跳（压力高时）。
- 音乐极少，以手风琴、口琴、收音机里的老歌为主（角色会唱歌）。

## 13. 风险与对策

- **涌现 ≠ 有趣**：纯模拟容易平淡或混乱。→ 「导演系统」监控张力曲线，在平淡时推送外部压力或调高叙事事件触发率，在过载时给喘息。
- **可读性**：玩家看不懂 NPC 为什么这么做。→ 记忆与意图可追溯（「他这么做是因为：3 天前你没分给他药」）。
- **成人内容的平台风险**：→ 主程序不含任何露骨内容，成人内容以独立数据包加载，便于 Steam 合规或独立分发。
- **敏感主题**：胁迫、暴力、独裁 —— 系统呈现后果而不奖励；开局提供内容开关（性暴力主题可完全关闭，关闭后相关行动不会出现在任何 NPC 行动库中）。

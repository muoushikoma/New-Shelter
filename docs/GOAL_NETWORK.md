# 目标节点网络与开放式人生结局 v0.1

> 本文档是《避难所》的**叙事骨架**，取代传统意义上的「主线」。
> GDD 中的生存、NPC、权力、亲密系统都是这张网的输入和输出。

---

## 0. 结论先行

- 游戏**没有主线**。唯一的默认目标是「活下去」。
- 游戏有一张**目标节点网络**。节点是「世界状态」（例如「我拥有通行资格」），不是任务。
- 每个节点有**多个解法**。解法由模拟里能做的具体动作组成（偷、换、修、谈、睡、打、伪造、等），不是对话选项。
- **NPC 和玩家共用同一张网**。周建国也想要通行证，阿娜也可能想离开。名额、资源和机会有限，所以人生路线之间天然会竞争。
- 战争时间线不再是剧情，它是一个**外部时钟**：它让窗口打开，也让窗口关上。
- 结局不从固定列表里选，而是由**几个维度组合**出来：你在哪、你是谁、你和谁在一起、避难所怎么样了、外面怎么样了、你是怎么走到这一步的。

## 1. 四个概念

| 概念 | 含义 | 例子 |
|---|---|---|
| **节点 Node** | 一个可判定的世界状态 | 「持有有效通行资格」「成为公认领导者」「与某人确立伴侣关系」「避难所能自给食物」 |
| **解法 Method** | 达成节点的一种方式：前提 + 一串具体动作 + 风险 + 后果 | 「伪造通行证」：需要空白证件、印章样本、会仿写的人；夜里去党部偷印章…… |
| **路线 Route** | 若干节点组成的人生方向。玩家可以「追踪」，也可以不追踪 | 「离开封锁区」「掌权」「共同生活」「重建」 |
| **门 Gate** | 节点/解法依赖的实体或条件。实体消失，门就关；新实体出现，新门就开 | 「军需官 X 还活着且驻扎在镇上」「宪兵队尚未撤离」「库存药品 ≥ 1」 |

**节点 ≠ 结局。** 节点完成后通常解锁更多节点。只有少数**终止节点**会结束这一局（例如「越过边境」「死亡」「被押送到劳动营」）。

## 2. 网络结构示意：以「离开封锁区」为例

```
                                  ┌───────────────────── 活下去（默认，始终存在） ─────────────────────┐
                                  │                                                                     │
        ┌──────────── 外部接触 ────────────┐          ┌──── 地位 ────┐          ┌──── 关系 ────┐
        │                                   │          │              │          │              │
  [知道军方驻点在哪]           [知道走私路线存在]     [被多数人认可]   [有可靠同伴]   [有伴侣]
        │   解法：地表探索 / 听广播        │   解法：黑市传言 / 审伤兵     │                        │
        │        / 问伤兵 / 跟踪周建国      │        / 搜尸体找地图          │                        │
        ▼                                   ▼          ▼                                           │
  [与军方建立联系] ◄──────────────── 共享节点 ───── [获得谈判资格]                                   │
        │   解法：送物资上门 / 结识军需官 / 告密换信任 / 以领导者身份谈判 / 亲密关系（成人接口）       │
        ▼                                                                                          │
  [持有通行资格]  ◄── 也可以绕过军方：伪造证件 / 偷证件 / 买走私名额 / 冒用死者身份                 │
        │                                                                                          │
        ├──► [越过边境]（终止节点 → 个人逃亡结局，可带人或不带人） ◄───────── [说服伴侣同行] ◄──────┘
        ├──► [在军方体系内谋职]（→ 依附 / 腐化 / 合作路线）
        ├──► [转卖通行证]（→ 财富 / 黑市路线）
        └──► [用通行证换避难所的物资补给]（→ 集体生存 / 权力路线）
```

要点：
1. 「与军方建立联系」同时属于逃亡、权力、依附、接管 4 条路线。
2. 「持有通行资格」至少有 9 种解法，每局真正可行的大约 3–5 种（取决于这局生成了哪些人、哪些势力、什么资源）。
3. 完成「持有通行资格」**不会**自动结束游戏。你可以走，可以卖，可以留下来用它换权力。

## 3. 解法的数据结构

解法写成**模板**，开局时绑定到这一局实际生成的人和势力上。所以同一份内容每局都长得不一样。

```jsonc
{
  "id": "pass.forge",
  "node": "has_exit_pass",
  "label": "伪造通行证",
  "requires": {                         // 前提：缺哪个，日志里就显示哪个
    "item": ["blank_permit", "ink"],
    "knowledge": ["permit_format"],     // 见过真证件
    "skill_any": [{ "who": "self|ally", "skill": "forgery", "gte": 40 }],
    "gate": ["faction.military_police.present"]
  },
  "steps": [                            // 每一步都是模拟里的具体动作
    { "do": "obtain", "target": "stamp_sample", "hint": "党部档案室 / 周建国的旧证件" },
    { "do": "craft",  "target": "forged_permit", "where": "any_private_room", "time_h": 6 },
    { "do": "pass_check", "check": "forgery_quality vs checkpoint_scrutiny" }
  ],
  "risk": [
    { "on": "step2", "type": "witnessed", "effect": "rumor:forger" },
    { "on": "step3_fail", "type": "arrest", "effect": "node:detained" }
  ],
  "consequence": [                      // 对网络中其他节点的影响
    { "open": "sell_forged_permits" },  // 学会伪造 → 新路线：做证件生意
    { "modify": "trust", "who": "ally_who_helped", "by": +15 }
  ],
  "tags": ["欺骗", "技术"],
  "adult": false
}
```

**解法分类标签**（用于结局叙述和 NPC 评价）：
`交易` `合作` `欺骗` `潜入` `暴力` `技术` `威望` `亲密` `依附` `告密` `牺牲他人`

## 4. NPC 共用这张网（与模拟打通的关键）

- 每个 NPC 开局从网络中挑 1–3 个**人生目标节点**，由人格和处境决定：周建国（权力欲高、怕死）→「持有通行资格」+「战后能证明自己坚守」；苏曼 →「避难所能自给」；阿娜 →「越过边境」。
- NPC 用 GDD §5.2 的计划器选择解法，和玩家一样受前提、风险、门的限制。
- **由此自然产生的情况**：
  - **竞争**：军方这周只给 2 个名额。你和周建国在争。
  - **合作**：阿娜也想走，但她没有地图，你没有证件样本。
  - **利用**：赵铁军发现你在伪造证件，他要一张，否则告发你。
  - **阻断**：苏曼的重建路线需要所有人留下，她会反对任何人离开，甚至藏起地图。
  - **连锁**：NPC 完成一个节点会改变世界状态。周建国拿到通行证跑了，钥匙就空出来了，你的权力路线因此突然打开。
- 玩家可以通过观察、深谈、偷看日记、听流言**推测**别人在追什么目标，推测不一定准。

---

## 5. 发现机制：玩家看不到整张网

- 开局只看得到「活下去」和几个与出身相关的节点（逃兵知道「宪兵在搜捕逃兵」，护士知道「药品可以换任何东西」）。
- 节点和解法通过**线索**解锁：NPC 闲聊、流言、广播、地表探索、搜尸体、审问、读档案、偷听。
- 日志中每个已知节点显示：

| 状态 | 显示 |
|---|---|
| 可行 | 所有前提已满足，可以开始 |
| 缺条件 | 列出缺什么（「需要：会仿写的人」） |
| 未知解法 | 「也许还有别的办法……」 |
| 已关闭 | 写明原因（「军需官死于炮击」「宪兵队已撤离」） |
| 被他人占先 | 「周建国拿到了最后一个名额」 |

- **追踪**是可选的。玩家可以追踪任意几条路线，也可以什么都不追踪，只凭直觉活着。

## 6. 动态开合：门与导演

**门的关闭**（每 tick 检查）：
- 实体消失：某人死亡、离开、被捕；某势力撤离或被消灭。
- 关系破裂：某个解法要求与 X 的信任 ≥ 60，而 X 现在恨你。
- 资源枯竭：最后一支抗生素用掉了。
- 外部时钟：「宪兵队撤离」后，所有依赖宪兵的解法关闭；「占领」后，旧政权的证件变成死刑证据。

**门的开启**：
- 新实体：有人敲门（一个走私贩、一个敌军逃兵、一个国际红十字的联络员）。
- 突发事件：炸开的墙后面出现了一条地下排水道 → 新解法「从排水道出镇」。
- 玩家与 NPC 的行为：你学会了伪造 → 新路线「证件生意」。

**导演规则**（保证每局都能玩下去，但不保证全收集）：
- 任何时刻玩家至少有 **3 个**「可行或差一步」的节点。低于这个数，导演会提高相关线索、来客、机会事件的出现概率。
- 不保证每局都能达成所有类型的结局；同一局里，有些路线注定打不开。
- 外部时钟的阶段偏移、势力组合、物资分布在开局随机，所以每局的「窗口期」不同。

## 7. 路线目录（初版，可扩充；路线之间共享节点）

| 路线 | 关键节点（举例） | 与其他路线共享 |
|---|---|---|
| **活下去**（默认） | 每日热量、取暖、治疗、不被驱逐 | 一切 |
| **离开封锁区** | 知道出路 → 通行资格 / 走私名额 → 越境 | 军方接触、财富、关系 |
| **掌权** | 掌握钥匙/枪/票数 → 公认领导者 → 制度稳定 | 军方接触（谈判）、腐化、重建 |
| **腐化**（掌权的变体，不是单独选择） | 以配给奖惩、以交易维系、清除异见 | 掌权、依附 |
| **财富** | 私藏、黑市渠道、垄断某种硬通货 | 离开、腐化 |
| **共同生活** | 确立伴侣 → 共同计划 → 一起离开 / 一起留下 | 离开、重建 |
| **集体生存** | 自给的食物/水/热源 → 等到救援 | 重建、掌权（以合作方式） |
| **社会重建** | 地面温室、水源、制度、生育 → 不再依赖外部 | 集体生存 |
| **依附** | 投靠某个强者或外部组织 → 被庇护 → （可能）失去自主权 | 军方接触、腐化 |
| **反抗** | 地下组织、政变、揭发 | 掌权 |
| **复仇** | 由创伤记忆触发；目标是某个人 | 暴力、告密 |
| **信仰** | 成为「先知」或其信徒 | 掌权 |

**依附与失去自主权**：这是一个状态，不是一条单行道。处于这个状态时，玩家的可选行动被大幅限制（被分配劳动、被限制行动范围、被要求顺从），但**始终保留至少一个逃离/反抗的解法**（找盟友、偷钥匙、等待外部局势变化、伺机报复）。涉及性剥削的部分通过成人内容接口呈现，意愿度为 `coerced`。如果「胁迫主题」开关关闭，这个状态仍然存在，但剥削形式换成强迫劳动、没收财物、人身控制。

## 8. 成人内容在网络中的位置

- 亲密/交易是部分解法的**一种实现方式**，地位和「交易」「欺骗」「暴力」一样，不是独立的奖励系统。
- **硬规则：任何节点都必须至少有一个不涉及成人内容的解法。** 内容校验工具会检查这一点，保证不开成人内容时游戏仍然完整（原则 8）。
- 涉及亲密的解法额外受意愿度系统约束：对方 NPC 是否接受由其模拟状态决定，玩家无法强行「完成任务」。
- 如果玩家被动成为别人解法中的筹码（比如周建国想用你去换他的通行证），这同样由模拟决定，并在网络里表现为「你的某个节点被他人威胁」。

## 9. 结局：组合而非列表

一局结束的方式有两种：
- **终止节点**：越境、死亡、被押走、被驱逐后失踪……此时立即结算。
- **终局清算**：外部时钟走到第四阶段（停火 / 政权回归 / 占领 / 崩溃），对所有还在避难所里的人统一结算。

结局由以下维度**组合**生成：

| 维度 | 取值（举例） |
|---|---|
| 你在哪里 | 境外 · 避难所 · 军营 · 劳动营 · 难民营 · 某组织内 · 死亡 |
| 你是谁 | 领导者 · 普通成员 · 依附者 · 被控制者 · 流亡者 · 囚犯 · 英雄 · 叛徒（在谁眼里） |
| 你和谁在一起 | 伴侣（名字）· 同伴 · 孤身 · 被所有人恨 |
| 避难所的命运 | 存续 · 自给重建 · 被接管 · 解体 · 全灭 |
| 外部局势 | 停火 · 政权回归 · 占领 · 崩溃 |
| 你是怎么走到这里的 | 主要解法标签的占比：交易 / 合作 / 欺骗 / 暴力 / 亲密 / 牺牲他人…… |

- 6 个维度的组合远多于 9 种。你列出的 9 种结局，作为**有名字的标志性组合**保留：命中特定组合时，会出现专门的结局插画和标题（「小领袖」「公社的冬天」「独自越境」……）。
- 结局**不分好坏**。结算画面讲的是一个人生：你活下来了吗、你成了谁、谁记得你、他们是怎么记得你的。
- 每个 NPC 也有自己的后日谈，同样由他们自己的节点完成情况生成，所以玩家能看到「周建国最后拿到了通行证，然后……」。

## 10. 保证「始终有事可做」

- 每个解法的步骤都是**模拟动作**（去某个房间、拿某件东西、在某个时间和某人说话、做出某个物品、通过某个检定），玩家能在地图上亲手去做。
- 对话只是动作的一种，而且对话本身也受关系值和信息约束。
- 日志里「缺条件」的条目就是天然的短期目标：「需要空白证件 → 党部档案室可能有 → 党部今晚有巡逻」。

## 11. 对现有 GDD 的修改

| GDD 章节 | 修改 |
|---|---|
| §1 理解 | 加入原则：没有主线，只有目标网络 |
| §2.3 战争时间线 | 定位改为「外部时钟」，作用是开关窗口 |
| §3 核心循环 | 加入「目标层」：日常生存 ↔ 推进节点 ↔ 世界状态变化 |
| §5 NPC | NPC 的长期目标来自同一张网 |
| §6.4 玩家的位置 | 以路线目录取代四条路线 |
| §8 事件 | 叙事事件的作用改为「开门 / 关门 / 提供线索」 |
| §9 结局 | 改为组合式结局 |
| §12 里程碑 | M2 加入节点网络框架，M3 起按路线填充解法 |

## 12. 内容量估算（首个可发售版本）

| 项 | 数量 |
|---|---|
| 路线 | 12 |
| 节点 | 约 80（其中共享节点约 30） |
| 解法模板 | 约 250（平均每节点 3 个；成人类约 15%，且从不是唯一解） |
| 势力模板 | 7（宪兵队、正规军后勤、占领军、走私团伙、地下抵抗组织、国际救援组织、宗教团体） |
| 标志性结局组合 | 30+，其余由组合自动生成 |

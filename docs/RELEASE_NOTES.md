## 避难所 · New Shelter 1.0.2

### 这一版改了什么

- **对话改成一问一答**：点一个人会打开对话窗口，里面有对话记录。你说一句，对方回一句，然后会出现追问、解释、道歉、给东西等后续选项。比如问「我哪里得罪你了」，对方会说出记恨你的那件事；讨吃的被拒绝，可以再求一次、借、或者拿烟换。
- **对方也会问你**：「你以前是干什么的？」（可以说实话、编一个、或者回避，撒谎可能被识破）、「你觉得领导这人怎么样？」、「什么时候加口粮？」（你是领导时，可以偷偷多给一份）、「你说我们能活着出去吗？」……你的回答会改变关系，对方会记住。
- **对话也做成了内容接口**：内置对话写在 `content/dialogue/base.json` 里，作者可以照着格式新增或改写：玩家开启的话题、NPC 主动问的问题、某个行动之后的追问，都能带条件、检定、效果。剧情事件也可以挂到场景物件上（比如电台、炉子），在物件菜单里多出一个选项。规范见 `docs/CONTENT_GUIDE.md` 第 5 章和 §4.8。
- **修复文字偏低**：像素字体自带的上边距，让所有文字都比预期低 3–4 个像素，标题栏、标签里的字会压到边框下面。现在按字形的实际高度对齐，并用自动检查把所有窗口、所有事件、两种字体、两种分辨率都过了一遍。
- 问 NPC「你以前是做什么的」时，对方会用第一人称回答，不再念第三人称的人物简介。

### 1.0.1

- **文字清晰了**：画面按屏幕实际像素绘制，不再从低分辨率放大。各种窗口大小和系统缩放（125%、150%）下文字都清楚。设置里新增「字体：像素 / 清晰」，清晰模式用系统黑体。
- **有音乐了**：程序生成的配乐（钢琴、弦乐、音乐盒），会按标题、白天、夜晚、紧张局势、结局切换情绪，放一段停一段。设置里可以单独开关音乐、调音量。
- **选领导不再那么容易**：刚认识几天的人不会把权力交给你。现在要过半数赞成才能当选，弃权也算在总人数里。支持度取决于熟悉程度、大家对你的好感和尊重、你的本事；自己推举自己会让人起疑。想掌权，先花几天时间出力、分东西、帮人。
- 修复：领导把「化雪」派成固定工作后，大家会一直化下去，储水无限增长。现在水够了就不再派这个活，水箱最多装 300 升。

### 安装提示

- **Windows**：exe 没有数字签名，第一次运行时 SmartScreen 可能提示「已保护你的电脑」，点「更多信息」→「仍要运行」。存档保存在用户目录，删除游戏不会丢档。
- **安卓**：需要在系统设置里允许「安装未知来源的应用」。手机屏幕上文字偏小，平板体验更好。
- 快捷键（桌面版）：空格暂停，1–4 调速，J 目标，R 关系，I 物品，L 日志，H 帮助，Esc 菜单，F11 全屏。

### 内容包

游戏支持不改代码地添加剧情事件、改写文本、新增人物、替换头像和插图、填写成人内容。

- **桌面版**：把 `content-template.zip` 里的 `content` 文件夹解压到 exe 所在的文件夹，在里面修改，然后重启游戏。这里的文件会覆盖游戏自带的同名文件。标题画面右下角会显示加载了多少内容，以及有没有出错。
- **安卓版**：内容打包在 APK 里，需要修改仓库里的 `public/content/` 后重新构建。
- 规范见仓库里的 `docs/CONTENT_GUIDE.md`（成人内容另见 `docs/ADULT_CONTENT_INTERFACE.md`）。

### 说明

- 18+：含成人主题、暴力与政治压迫的描写。成人内容默认关闭，开启后也需要内容包才会显示正文。
- 本版自带 4 个示例剧情事件；成人内容包只有接口与模板，没有正文。
- 像素字体：Fusion Pixel（SIL OFL 1.1）。
